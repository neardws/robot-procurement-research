# Robot Research Data

This folder contains the structured dataset used by the Web App and report.

- `robot_research_data.json`: candidate robots, sources, scores, and evidence notes.

Important limitations:

- Prices are intentionally separated by confidence and type.
- `厂商正式报价项` means no reliable public current price was confirmed, so procurement should request a formal vendor or authorized-channel quote.
- `供货状态待确认` means the model is historical, supply is unclear, or the current public product page is insufficient for direct procurement.
- Scores are planning aids, not final procurement decisions.
- A procurement team should request formal quotes before bidding or purchase.
