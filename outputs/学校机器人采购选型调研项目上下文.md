# 学校机器人采购选型调研项目上下文

## 目标

面向学校科研、教学和后续落地项目需求，系统调研并比较可采购的实体机器人平台，最终输出一个可交互 Web App，用于浏览型号、筛选类别、查看论文使用情况、比较性能参数、追踪价格和来源，并形成采购短名单与试点建议。

## 调研对象

本项目关注多种机器人形态：

1. 机械臂
2. 人形机器人
3. 机械狗
4. 复合型机器人，例如轮式底盘上方搭载机械臂
   - 末端执行器可以是灵巧手
   - 末端执行器也可以是二指夹爪、三指夹爪、吸盘、快换工具等

## 核心要求

### 1. 服务科研需求

优先关注在相关论文、开源项目、实验室案例和机器人社区中出现频率较高、应用较广的型号。判断科研通用性时，应重点记录：

- 是否常见于论文实验平台。
- 是否有 ROS、ROS 2、SDK、仿真环境或开源示例。
- 是否容易获得传感器、末端执行器、底盘、算力和软件生态支持。
- 是否适合多课题复用，例如操作、导航、具身智能、多模态感知、强化学习、人机交互等。

### 2. 收集详细资料

每个候选型号应尽量收集：

- 官网地址。
- 厂商或代理商信息。
- 公开价格、教育价格、代理报价或估算区间。
- 采购配置说明。
- 关键性能参数。
- 软件接口和开发生态。
- 论文、项目或实验室使用证据。
- 交付周期、售后支持、培训和维保信息。
- 安全认证、使用限制和场地要求。

### 3. 考虑落地应用

除科研价值外，还需要从实际项目落地角度综合评估：

- 可用性：稳定性、易维护性、备件和售后。
- 集成性：是否方便接入校内系统、实验平台、数据采集流程和自研算法。
- 可扩展性：传感器、夹爪、灵巧手、移动底盘、算力模块是否可扩展。
- 安全性：急停、防碰撞、力控、安全围栏、人机共处能力。
- 成本：本体、配件、运输、关税、培训、维保、软件授权和二次开发。
- 场地适配：实验室空间、电源、网络、地面、负载、噪音和安全管理。
- 教学适配：学生上手难度、文档质量、课程示例和多用户管理。

## 选型维度

- 机器人类别：机械臂、人形机器人、机械狗、复合型机器人。
- 科研通用性：论文出现频率、开源生态、实验室采用度、可复现实验数量。
- 性能参数：自由度、负载、臂展、精度、速度、续航、载重、算力、传感器。
- 软件生态：ROS/ROS 2、SDK、仿真、API、示例代码、社区活跃度。
- AI 与具身智能适配：视觉、语言、控制、模仿学习、强化学习、数据采集能力。
- 末端与扩展：灵巧手、夹爪、快换、力传感、相机、激光雷达、深度相机。
- 部署与维护：交付、安装、培训、维保、备件、远程支持。
- 安全与合规：急停、防护、碰撞检测、认证、校园实验室安全要求。
- 成本与采购：价格、教育优惠、代理渠道、可采购性、付款和保修条件。
- 落地难度：系统集成、算法适配、场地要求、人员培训、项目周期。

## 来源记录要求

涉及最新型号、价格、性能参数、论文使用情况、厂商信息和采购渠道时必须联网核验。每条关键结论都应记录：

- 信息来源名称。
- URL 或 DOI/arXiv 链接。
- 访问日期。
- 来源类型：官网、规格书、价格页、代理报价、论文、GitHub、实验室项目、视频演示、招投标信息、第三方评测等。
- 可信度备注：官方来源优先；非官方价格和二手报价必须标注不确定性。
- 关联结论：该来源支撑了哪项参数、价格、科研使用或落地能力判断。

## 最终输出形式

最终交付一个 Web App，建议包含：

- 总览页：按类别展示候选机器人数量、价格区间、科研通用性和落地适配概览。
- 筛选与搜索：类别、价格、负载、自由度、ROS 支持、论文热度、国产/进口、可采购性。
- 对比矩阵：选择多个型号横向比较参数、价格、生态、优缺点和风险。
- 机器人详情页：官网、图片、参数、配置、价格来源、论文证据、适用场景、采购注意事项。
- 短名单页：按学校科研、教学、落地项目分别给出推荐组合。
- 来源页：集中展示所有证据来源，方便审计和复查。

## 后续优先问题

正式调研前建议先确认：

1. 预算范围：单台预算和总预算。
2. 主要用途：科研、教学、竞赛、展示、校企项目或真实场景落地。
3. 重点方向：具身智能、机械臂操作、移动操作、人形机器人、四足巡检、多机器人协同等。
4. 是否偏好国产设备，或是否可以采购进口设备。
5. 实验室现有技术栈：ROS、ROS 2、Python、C++、Isaac Sim、MuJoCo、Gazebo 等。
6. 场地条件：实验室面积、地面、电源、网络、安全管理要求。
7. 是否需要厂商培训、课程资源、二次开发支持和本地售后。
